# 界面精简 · 2026-11-12

## 如何开始

打开 http://localhost:4174/#tasks，查看本轮原始公告实际生成的三项任务、准备安排和提醒。当前为历史资料回放，不改写原年份。旧经典回归在右上角“体验演示”，不是正式模型验收入口。

## 入口位置

| 功能 | 新位置 |
| --- | --- |
| 一次设置课程范围、自动处理后续变化 | 任务 → 自动跟进 |
| 临时导入课程原文、粘贴说明 | 任务 → 手动导入 |
| 要求、来源、时间与预计用时 | 点击任务 → 详情／修改 |
| 完成确认、推迟准备、暂停提醒 | 任务详情 |
| 实际用时反馈 | 任务详情 → 实际用时（选填） |
| 每周空闲、班级、设备与提醒偏好 | 计划 → 空闲设置 |
| 会议、已有课程等占用 | 计划 → 添加已有安排 |
| 自然语言调整 | 计划上方 → 调整安排；假设或勾选“只试算”时展示预览 |
| 模型连接、调用记录、JSON 接入、导出 | 右上角设置 |
| 回放时钟 | 顶部时间控制 |

旧的 overview、ai、data 页面链接均回到任务页。模型和数据工具改为按需打开，主界面不再展示流程长条、重复统计卡片、整页说明和调试 JSON。

## 本次变化

保留紫金色系，六项主导航缩成三项。任务使用简洁列表，计划把准备、固定活动和已有安排合并为时间线。导入、详情、原文和试算共用一个弹窗，切换内容时不会叠加新窗口。

页面只显示当前状态、下一步操作及需要补充的信息。模型调用费用、重启后填写 key 等提示只在对应设置中出现，不在各页面反复强调。

最初精简保留了底层排期与提醒。随后增加后台自动资料跟进和意图驱动调整，4174 已升级；主界面仍只增加一个入口和一行处理摘要，详细入口路径与记录收进同一弹窗。原始课程包未修改。
